# Review contract
Read the task brief, exact global constraints and implementer report; inspect packaged net diff. Two explicit verdicts: spec compliance and code quality. Read-only except own report; no subagents, no git mutations, no new research runs. Do not repeat already-run tests; only a bounded test for a concrete uncovered doubt. Code outside diff only for named concrete shared-interface risks. Findings include file/line, impact and minimal resolution. Critical/Important must be addressed; minor recorded and triaged at final review. Report cross-task verification limits to root, not speculative expansion. Never print/write git identifiers or SHA256; package uses named base refs and subjects. Warnings graded by their actual implication, not automatically a correctness failure. Root owns broader final review and full regression once.
