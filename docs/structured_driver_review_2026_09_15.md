## 全分支审查

最终审查发现两项重要问题，已完成独立合成复现与统一修复，58 项覆盖测试通过，两项问题均已修复并通过复审：

1. 运行器将非空历史读取路径保存在 task 审计字段，而 prepared 从数值数组重建、路径为空；导出器错误要求二者相等。应保持审计路径与模型数值输入分离，通过数组/掩码校验绑定历史。
2. 新增历史代码无条件按 NumPy 方式查找 track ID，导致旧 v1 原本合法的列表输入报错。应沿用已验证对象顺序/规范化数组，默认 v1 与 opt-in 历史都覆盖列表窗口。

输入模块长度 Minor 明确判定不阻断：这些部分服务同一有限 receiver 契约且复用几何/投影逻辑。本批不拆模块；出现实际第二调用方或生命周期冲突时再提取。初始化与运行 ID 两项实施决定均获最终审查认可。

## 实施决定

增加显式未训练初始化入口，解除“采集需要检查点、训练需要已采集任务”的启动依赖。固定 seed、完整规格和 untrained 身份通过同一个加载器读取；本轮只在临时合成目录测试。若后续采集组织不适配，代价是调整初始化/采集接口，P/F 方法语义无需改变。


独立初始化/训练增加显式 `training_run_id`，保存于 `model_version.training`，复制/加载检查点和同一恢复链保留身份。它弥补同名、同 seed、同步数仍可能对应不同权重的问题；直接参数/优化器/输入比较仍保留。该字段不是内容指纹、防伪证明或网络特征。代价是相同权重的独立训练也会被保守视为不同查询策略绑定，复用需要明确重绑定。
