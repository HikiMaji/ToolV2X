# 原驾驶模型的参数更新与重载检查

日期：2026-09-11。与 MTR 六组稳定性实验独立执行，属于已授权驾驶适配工作的入口验证。

本项只回答原 V2V-GoT / V2V-LLM 的 LoRA 和实际使用的点云 projector 能否获得正确梯度、执行真实更新并保存重载。每个初始化、每种解码方式各检查一次；每次只有一个训练帧，Ego/P/F/PF 共用同一个模型，累计四动作损失后执行 **一次** AdamW 更新。不能据此选择初始化、解码方式或宣称适配收益。

- 使用已经核验的真实训练帧 `2022-03-15-10-09-50_0:10`、因果特征及历史紧凑工具证据。它来自旧 MTR，专用于入口检查；正式适配必须重新使用本轮最终冻结的 MTR 物化证据。
- 从训练索引核验记录归属，标签来自单独的离线标签文件。Q8→Q9 保留该旧运行实际生成的 Q8；direct 用相同已选择证据构造 Trajectory，无 Q8 输入。旧生成父回答来自 GoT，不是当前候选的在线自生成分布，所以这些行不能冒充正式 2×2 训练集。
- 原模型仍为 LLaVA 7B + 发布 LoRA；训练加载必须保留原 LoRA 模块。只开放已有 LoRA A/B 和实际使用的 `mm_projector`，冻结语言基础参数、CLIP 和当前浅层分支未使用的 `mm_scene_projector`。默认推理继续合并 LoRA。
- 训练使用原 `train_mem.py` 指定的 `flash_attention_2`，普通推理保留 SDPA。已实际观察 torch 2.1.2 内置 Flash 在本机 sm89/head_dim128 训练上不受支持，默认 SDPA 回退在长 P 行反向传播时 OOM；两个零优化步的失败目录保留。补齐训练内核后仍使用相同输入及原损失，不裁剪证据来绕过检查。
- 使用原训练脚本的 BF16 基础计算、LoRA 学习率 2e-4、projector 学习率 2e-5、weight decay=0。可训练参数和 AdamW 状态用 FP32，梯度裁剪上限 1；按所有监督行平均损失后做一次更新。上下文仍是当前工具接口的 4096；这不是原论文批量大小、训练轮数或分布的复现。
- 每行执行原多模态准备和原 causal language modeling loss，确认提示/点云 token 的标签均为 -100，只有回答和结束符参与损失。保存 loss、真实梯度、更新前后参数差、冻结参数无梯度检查及峰值显存。
- 新目录保存可训练 adapter、完整原 projector 文件、tokenizer/config、输入行和过程报告。用标准推理入口重新加载，核对 adapter/projector 文件与保存前参数并执行真实生成。重载生成只检查读取路径，不作质量比较。
- 如发生加载、梯度、格式或显存失败，保留真实日志，先修复具体入口问题。上述检查完成后才具备执行正式共享驾驶适配的基础。

2026-09-11 内核资源补充：从 PyPI 的 FlashAttention 2.5.9.post1 原始源码构建本地 wheel，源码压缩包保留。构建副本仅编译本模型需要的 head_dim128 FP16/BF16 前向、反向和 split 内核，API 显式拒绝其他 head dimension；省略 sm90，保留 sm80 代码供本机 sm89 执行。这是有限范围的本地构建，不宣称完整原版包或其他模型可用。补丁、构建及实际 GPU 检查记录保存在 `outputs/resources_flash_attention_v1/`。主环境只安装该 wheel，不升级 torch/Transformers；四组合使用新的运行目录，旧失败证据保留。
