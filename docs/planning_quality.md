# 已有 Q8/Q9 输出的离线质量检查

本次评价读取之前保存的原 V2V-GoT 回答，不重新生成、修改回答或训练驾驶模型。评价入口为 `src/evaluation/planning.py`；明细和分母保存在 `outputs/planning_quality_v1/rows.jsonl`、`summary.json`。三组运行实际只有两个不同的决策帧，属于诊断，不能作为 P/F 收益或表示优劣的统计结论。

## 评价方法

Q8 与原 V2V-GoT 标签函数产生的速度、转向类别比较。标签来自观测到的自车未来轨迹，表示模仿目标，不代表唯一最优或安全决策。

Q9 必须保留实际生成的 Q8 父回答，并从原始文本解析六个有限数值坐标。解析失败保留在全部尝试次数中；不补点、不删掉失败动作。成功轨迹与固定 ego(t) 坐标下的自车未来位姿比较，评价时刻为 0.5、1、1.5、2、2.5、3 秒；缺失终点不由更早时刻替代。表内 ADE/FDE 仅对可解析且有标签的轨迹计算，失败率单列。

动力学检查从当前原点 (0,0) 开始：相邻位置差除以 0.5 秒得到分段平均速度，速度位于区间中点。当前速度方向近似为 ego +x，首段平均速度与当前速度之差除以 0.25 秒得到初始加速度估计。该估计用于发现输出跳变，不是车辆动力学仿真；重复未来点只记录模式，不直接判为失败。未评价碰撞或闭环驾驶。
